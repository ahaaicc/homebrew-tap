# homebrew-tap

[mtm](https://github.com/ahaaicc/mtm) 的 Homebrew Tap — 终端看板，管理多个 AI agent（Claude Code、Codex CLI、Droid）上的并行任务。

## 安装

```bash
brew install ahaaicc/tap/mtm
```

注意：homebrew-core 里已有同名的 `mtm`（另一个项目），请务必使用全限定名 `ahaaicc/tap/mtm`。

## 升级

```bash
brew update && brew upgrade ahaaicc/tap/mtm
```

Formula 由 GoReleaser 在 [mtm 仓库](https://github.com/ahaaicc/mtm)打 tag 时自动更新，请勿手动编辑 `Formula/`。
